# Bangs that open in Helium

Status: resolved

Blocked by: 01

`!yt cats` or `cats !yt` shows one row that opens the finished search URL in Helium. A bare bang opens the site's home page. Needs the final list, triggers, per-bang home pages and the default web-search engine; see `bangs.md`. Check each URL before committing it.

## Comments

Built with 43 bangs whose URLs were requested on 2026-10-24 (some sites answer bots with 403 or a login wall; those are marked in `data/launcher-bangs.toml`). The three AI bangs are best effort. Default web-search engine is DuckDuckGo; set `default_engine` in `~/.config/dojo/bangs.toml` to change it.
