# Colour picker and conversion

Status: resolved

Blocked by: 01

A Pick Color command using Niri's `PickColor` request, copying hex, rgb(), hsl() or oklch(). An inline row for a typed colour shows a swatch, every format and contrast against black and white. Recent picks join the history.
