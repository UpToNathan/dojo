# USB controller navigation and launcher controls

Status: deferred

Use the touchpad as the system mouse, sticks to navigate focused windows and
columns, D-pad shortcuts to open configured applications, and face buttons to
operate the Dojo launcher and cycle focus. Every other button remains
unassigned.

## Comments

The Dojo-specific controller service and bindings were removed for now at the
user's request. The controller touchpad remains available as normal system
mouse input. Revisit this issue if custom controller navigation is wanted
again.
