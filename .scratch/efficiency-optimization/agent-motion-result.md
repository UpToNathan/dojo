# Agent motion output scheduling

The compositor now marks an output as having an ongoing agent animation only when a moving cursor is currently on it or is traveling to it. Keeping the destination active preserves a frame source when the cursor crosses a gap between outputs. Each cursor position change queues its previous and new outputs so crossing and disappearance erase old pixels. Starting a move also queues its destination. Arrival queues the final cursor output and clears movement as before.

Move and Wait no longer unconditionally queue all outputs. Key, button, axis, focus, reset, and cursor-theme changes preserve their prior redraw behavior because their activation effects need separate verification. Connection ownership, independent seats, pointer interpolation, held-input cleanup, blocking arrival, and the existing one-shot wait fallback are retained.
