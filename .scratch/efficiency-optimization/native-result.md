Screenshots now use ImageReader::into_dimensions on the original PNG rather than decompressing a full pixel image solely to read its dimensions. The response still base64-encodes the original PNG and uses the same output-relative logical mapping. Existing 32 MiB compressed input and five-second capture limits remain. PNG metadata parsing has a 32 MiB allocation limit; accepted dimensions must be nonzero, no larger than 32,768 per axis and within a 128 * 1024 * 1024 pixel budget, equivalent to the old decoder's default 512 MiB budget for RGBA8 output. Standard 8K and 16K images fit. This validates metadata rather than fully decompressing image data; the capture boundary still requires grim to exit successfully. Three pure screenshot tests cover known dimensions, excessive width, and malformed/truncated headers. Parent owns root binary compilation and screenshot test execution.

AudioClip::from_pcm validates PCM as before and moves already-normalized 16 kHz mono storage directly. Stereo still downmixes; other rates still use the existing resampler. Transcriber::transcribe now consumes AudioClip, pads its existing vector and borrows the resulting storage only at the native engine call. All four CLI paths use that single operation. The old cloning API and its unused borrowed sample accessor were removed. Documentation examples now move clips. Model lifetime, checksum verification, microphone lifecycle and native session scratch cleanup remain unchanged. Three pure tests cover native-rate samples/duration, stereo downmix and malformed/nonfinite PCM admission.
