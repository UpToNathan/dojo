# Voice implementation result

Implemented in the current dirty worktree based on HEAD `7fb1e4ffa79843314624783fe8f302c734322caf`. Files changed are tools/speech/voice.mjs, tools/speech/t3-client.mjs and tools/speech/dojo-voice.service. Added tools/speech/voice.test.mjs. Existing untracked speech work remains intact. No native package, Cargo files, installed configuration or running services were changed.

The voice server acquires its advisory singleton lock before native preload and socket replacement on every entry path. A `flock --no-fork` helper prints acquisition readiness, then execs a pipe-waiting cat process. This adds one small blocking helper rather than a second waiting Electron/Node interpreter. EOF releases the lock after normal shutdown or parent process death. The fallback no longer uses a separate conflicting lock convention. Failed startup releases ownership.

Conversation settlement now uses one deadline rather than a permanent one-second interval. Recording, submission and active runs defer the deadline. Status/history inspection does not count as a new interaction. Settlement closes the voice WebSocket while the native model remains warm. Optional whole-service idle exit still works and flushes outside its own command queue. Shutdown cancels capture, closes the worker input and client, drains accepted queued work, then flushes state.

Healthy same-thread subscriptions persist across follow-ups. Reconnect supplies the last consumed sequence and falls back to a snapshot after a replay rejection. Connection establishment is shared. Reconnect has one timer and exponential backoff capped at 30 seconds. Streaming sequence-only writes coalesce for 250 milliseconds; completion/dispatch/lifecycle transitions remain immediate. Writes serialize with immutable JSON snapshots. Existing history/resume data remains complete. This bounds queued work and write frequency, not total retained history size.

The command/event queue and T3 pending requests are capped at 128. Accepted work completes; additional work receives a busy error. Subscription ACK follows consumption, so processing can apply backend backpressure. Overflow closes the backend connection for sequence recovery rather than silently dropping events. Interrupted subscriptions release their pending entries immediately. Malformed WebSocket JSON closes the connection instead of throwing out of the listener.

The systemd entry marks its already-established devenv environment with DOJO_VOICE_DEVENV=1. That path invokes dojo-speech directly without a second devenv shell. Outside-shell CLI fallback retains native devenv activation. No speculative library path removal was made. The shell wrapper itself is unchanged.

Tests use isolated temporary runtime/state directories, mock native/backend boundaries, and open no microphone or model. No T3 requests, host installations or service restarts occurred. Native in-flight cancellation and audio copies remain unchanged. Parent owns activation and live continuity/resource verification; no battery savings are claimed.

Final ownership review added immediate listener/client closure and native stdin closure on unexpected lock-holder exit. Shutdown shares one completion promise, avoids recursive cleanup, and waits for orderly lock release. Socket unlink checks the bound inode/device identity, so an old coordinator cannot remove a successor's socket after lock loss. Unix socket clients are explicitly capped at 32; the 16 KiB request and 45-second timeout limits remain. Durable history is retained without pruning; total history metadata and its in-memory representation remain unbounded and are reported as a limitation. Splitting an archive without changing history/resume behavior is a separate unit.
