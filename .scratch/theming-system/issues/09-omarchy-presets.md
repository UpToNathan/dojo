# Add palettes from Omarchy's built-in themes

Status: resolved

Add several built-in Omarchy color palettes to Dojo's static preset catalogue,
including Osaka Jade. Port palette data only; Dojo keeps its own wallpaper
selection and application behavior. Preserve upstream semantic colors and mark
the resulting terminal palettes as adaptations where Omarchy does not provide
a standalone ANSI palette.

Added Osaka Jade, Miasma, Ristretto, Flexoki Light, and Matte Black from the
pinned Omarchy quattro `colors.toml` files. Each appears under its own theme
family in the preset catalogue. Updated license/provenance notes. No Omarchy
wallpaper assets are included.
