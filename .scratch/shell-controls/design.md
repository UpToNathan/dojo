# Chosen control interfaces

Use candidate B's NetworkManager domain worker and separate native Wi-Fi overlay.
The independent judge agreed on that base. Graft candidate A's compact typed
power action vocabulary and a shared clock using the existing libc dependency.
The frame owns placement and trigger input bounds; the panels own focus and
dismissal. Read-only refresh never enters the mutation state.

The Wi-Fi interface hides NetworkManager object paths and dictionaries behind
network IDs, snapshots and actions. Saved profiles use activation; missing
secrets and new personal networks use a native password prompt and D-Bus
credential dictionaries. Prefer this direct handoff over a separate secret
agent unless actual profile behavior requires one. This keeps passwords out of
process arguments while avoiding a second asynchronous prompt lifecycle.

The user selected power actions only. The system menu therefore contains
Suspend, Hibernate, Log out, Restart and Shut down, with no settings shortcuts. Power
capabilities come from logind; logout uses Niri IPC. The existing host has no
screen locker, so this scope does not add a nonfunctional Lock command.

Candidate artifacts and the rubric review are in
`/tmp/dojo-shell-controls-design-{a,b}.md` and
`/tmp/dojo-shell-controls-judge.md`.
