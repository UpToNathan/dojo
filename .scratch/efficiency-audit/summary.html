Recommended sequence

1. Release baseline and tray eventsMeasured hot threads + verified repeated work

Replace 25 ms channel polling and repeated property/pixmap retrieval with blocking waits and change signals. Retain a slow fallback for imperfect tray providers. Measure an optimized resident build before promising savings.

2. Sleep between visible changesVerified unnecessary scheduling

Notify the frame only when displayed state changes. Share host-state updates across outputs. Static speech bubbles should sleep between entry and exit; preserve input and active feedback.

3. Give the idle manager an energy-saving planVerified live: no enabled idle actions

Stasis is resident but its effective action plan is empty. Define battery and AC lock, screen-off, and suspend deadlines, preserving active-work and media inhibition.

4. One voice owner, bounded integration workTwo live coordinators + verified startup race

Acquire one lock before loading a model or replacing the socket. Coalesce history writes, retain healthy subscriptions, and use idle deadlines. Keep the fast warmed speech worker.

5. Allocate only the graphics resources being usedVerified allocation and retention paths; savings unmeasured

Allocate path scratch textures only for scenes with paths. Use bounded thumbnail ownership for wallpaper previews. Measure blank reservation renderer costs before redesigning them.

6. Profile capture and blur, then test battery policyMeasured graphics activity; energy benefit unresolved

wluma shows ongoing GPU activity and may also save panel power through brightness adaptation. Check capture cadence and resolution. Verify actual blur cropping. Measure net battery energy before changing appearance or unloading the speech model.
