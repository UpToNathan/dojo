Hokum for Wayland compositors with `zwlr_layer_shell_v1` (niri, sway,
Hyprland), for Linux x86_64 and aarch64.

- Hokum is on the AUR for the first time: `yay -S hokum-bin` (0.0.1 and
  0.0.2 never reached it).
- From 0.0.2, which AUR users never got: Capsule, with app icons, is the
  default theme for new installs (and for any `config.kdl` that names no
  theme); a config with `theme "…"` keeps its theme. Web notifications from
  Chromium-based browsers no longer show the browser's per-site "Settings"
  button.
- Debian/Ubuntu and Fedora/openSUSE: install `hokum.deb` or `hokum.rpm` below
  with `apt` or `dnf`, or always the newest stable from
  `https://anoma.ly/release/hokum/desktop/stable/linux-x64-deb` (`-rpm`, or
  `linux-arm64-…`). The bare executables are below too.
- Hokum starts through D-Bus activation on the first notification; to start
  it with the session instead, run `systemctl --user enable --now hokum.service`.
