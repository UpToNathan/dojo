Click-to-update: Hokum now tells you when a new build is out.

- The running service checks for a new build a minute after it starts and
  then hourly, fetching its channel's release manifest as
  `hokum/<channel>/<version>` (#6).
- When a different build is out, one Hokum card offers it. Nothing installs
  without a click (#7).
- A plain install you can write (`~/.local/bin/hokum`) updates when you
  click the card's Update button: Hokum downloads the new executable, checks its size and sha256,
  replaces itself and restarts. For installs from the AUR, .deb or .rpm the
  card shows the package manager's update command instead, and its button
  copies it (#7).
- New command: `hokum update` checks now, and `hokum update --install` does
  what the card's Update button does (#7).
- Set `check-for-updates #false` in `behaviour` in `config.kdl` to turn the
  checks off.
- The check compares the sha256 of Hokum's own executable, so the card no
  longer offers an update when you already run the current build (#8).
