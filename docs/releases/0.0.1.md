The first Hokum release: a freedesktop notification daemon for Wayland
compositors with `zwlr_layer_shell_v1` (niri, sway, Hyprland), for Linux
x86_64 and aarch64.

- Install from the AUR: `hokum-bin`, or unpack a tarball below.
- Hokum starts through D-Bus activation on the first notification; to start
  it with the session instead, run `systemctl --user enable --now hokum.service`.
